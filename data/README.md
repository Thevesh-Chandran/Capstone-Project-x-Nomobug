# Local Data Workspace

Use this folder for local CP2 data profiling and generated analytical files.

- `samples/`: small, anonymised API or parsing samples.
- Future `raw/`: untouched company exports and source snapshots.
- Future `interim/`: cleaned or matched working files.
- Future `processed/`: dashboard-ready local outputs.

Raw company data and files containing customer or employee information must remain local and must not be committed to GitHub.
