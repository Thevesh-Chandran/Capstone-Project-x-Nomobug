Several Gold intermediates expose sale IDs or property hashes, including `dashboard_recurrence_windows` and `dashboard_warranty_package_metrics`. No unauthorized disclosure was demonstrated, but a dashboard-prefixed name is not privacy approval. **Fixed locally:** default reconciliation now follows bounded same-model release wrappers, the current payment serial sidecar and current candidate materialized facts, and checks Gold wrapper consistency. An explicit approved-management schema gate rejects direct/nested identity/contact fields before promotion; regression checks and live aggregate schema inspection passed. **Remaining:** deploy these fixes and verify actual Looker sources, dataset/viewer access and rendered charts.

The 100-service held-out sample has five positives; threshold accuracy is 94% versus a 95% always-no-callback baseline. Reviewing the top 20 finds four positives, which is useful exploratory ranking evidence but too small for dependable accuracy. The inspected first-service diagnostic misses all eleven positives; the separate 13-service/one-positive later check also misses its positive. Nine obsolete cancellation/status training anchors remain frozen. **Fix (Proposed):** collect stronger source-backed outcomes and evaluate a separately governed candidate on untouched data; do not optimize this model by repeatedly selecting against the same held-out outcomes.

8. **Other operating limits.** Collector prediction receipts and latest state are durable, but full historical run journals are not persisted, and stored last-success paths can refer to ephemeral directories.
